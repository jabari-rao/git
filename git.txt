JENKINS

# Jenkins CI/CD Pipeline Setup (Freestyle Jobs)

## Prerequisites

Before starting, ensure the following are installed and configured:

* Java (JDK 8 or higher)
* Jenkins (running on http://localhost:8080)
* Maven
* Git
* A Git repository containing a Maven project (with `pom.xml`)

---

## Step 1: Launch Jenkins

1. Start Jenkins.
2. Open a web browser and go to:
   http://localhost:8080
3. Log in with your credentials.

---

## Step 2: Create Job 1 (Compile Stage)

1. Click **New Item** on the Jenkins dashboard.
2. Enter the name: `job1`.
3. Select **Freestyle Project** and click **OK**.

### Configuration:

* **Source Code Management**:

  * Select **Git**
  * Enter repository URL
  * Add credentials if required

* **Build Triggers**:

  * Select **Poll SCM**
  * Schedule:

    ---

* **Build**:

  * Add build step → **Invoke top-level Maven targets**
  * Goals:
    compile

4. Click **Save**

---

## Step 3: Create Job 2 (Test Stage)

1. Click **New Item**
2. Enter the name: `job2`
3. Select **Freestyle Project** → Click **OK**

### Configuration:

* **Source Code Management**:

  * Same Git repository

* **Build Triggers**:

  * Select **Poll SCM**
  * Schedule:

    ---

* **Build**:

  * Add build step → **Invoke top-level Maven targets**
  * Goals:
    test

4. Click **Save**

---

## Step 4: Configure Post-Build Action (Link Jobs)

1. Open **job1**
2. Click **Configure**
3. Scroll to **Post-build Actions**

### Add:

* Select **Build other projects**
* Enter:
  job2
* Enable:
  ✔ Trigger only if build is stable

4. Click **Save**

---

## Step 5: Create Pipeline View

1. Go to Jenkins Dashboard
2. Click **"+" (New View)**
3. Enter name:
   pipeline2
4. Select **Build Pipeline View**
5. Click **Create**

### Configure:

* **Initial Job**:
  job1
* **Display Options**:
  ✔ Based on upstream/downstream relationship
* **Number of displayed builds**:
  1
* **Refresh frequency**:
  3 seconds

6. Click **Save**

---

## Step 6: Run the Pipeline

1. Open **job1**
2. Click **Build Now**

### Execution Flow:

job1 (compile) → job2 (test)

3. Open **pipeline2 view** to see visual pipeline execution

---

## Troubleshooting

### Common Issues:

1. **Maven not found**

   * Configure in: Manage Jenkins → Global Tool Configuration

2. **Git errors**

   * Verify repository URL and credentials

3. **Missing pom.xml**

   * Ensure project is a valid Maven project

4. **Java issues**

   * Set JAVA_HOME correctly

5. **Jobs failing**

   * Check Console Output for detailed errors

---

## Optional Test

To verify Jenkins setup:

* Replace build step with:
  echo "Hello Jenkins"

If this works, Jenkins is configured correctly.

---

## Conclusion

This setup creates a simple CI pipeline where:

* `job1` compiles the code
* `job2` runs tests after successful compilation
* Pipeline view shows execution flow visually

STEP-BY-STEP GUIDE: AZURE DEVOPS CI PIPELINE WITH MAVEN + SELF-HOSTED AGENT

--------------------------------------------------
PART 1: CREATE AZURE DEVOPS PROJECT
--------------------------------------------------
1. Go to https://dev.azure.com
2. Sign in with your Microsoft account.
3. Click “New Organization” (if not already created).
4. Inside the organization, click “New Project”.
5. Enter:
   - Project Name
   - Visibility (Private/Public)
6. Click “Create”.

--------------------------------------------------
PART 2: CREATE CI PIPELINE
--------------------------------------------------
1. Go to your project dashboard.
2. Click “Pipelines” → “Pipelines”.
3. Click “New Pipeline”.
4. Select “GitHub”.
5. Authorize Azure DevOps to access your GitHub account.
6. Select your repository.
7. Choose “Maven” template.
8. Review the generated azure-pipelines.yml file.
9. Ensure Maven goals include:
   clean install
10. Click “Save and Run”.
11. Commit the pipeline YAML file to your repo.

RESULT:
- CI pipeline created
- azure-pipelines.yml added to repository

--------------------------------------------------
PART 3: VERIFY BUILD
--------------------------------------------------
1. Go to Pipelines dashboard.
2. Click on the running pipeline.
3. Check logs for:
   - Build success
   - Test results
4. Fix errors if any.

--------------------------------------------------
PART 4: OPTIONAL TASKS
--------------------------------------------------
- Add test steps
- Publish artifacts
- Deploy to Azure services (App Service, AKS, etc.)

--------------------------------------------------
PART 5: CREATE SELF-HOSTED AGENT
--------------------------------------------------
1. Go to “Project Settings”.
2. Click “Agent Pools”.
3. Click “Add Pool”.
4. Name the pool (e.g., TestAgent).
5. Open the pool → Click “New Agent”.
6. Download the agent package.

--------------------------------------------------
PART 6: CONFIGURE AGENT (ON YOUR MACHINE)
--------------------------------------------------
1. Extract the downloaded zip.
2. Open command prompt in that folder.
3. Run:
   config.cmd

4. Enter:
   - Organization URL
   - Personal Access Token (PAT)
   - Agent Pool Name
   - Agent Name

--------------------------------------------------
PART 7: CREATE PERSONAL ACCESS TOKEN (PAT)
--------------------------------------------------
1. Click profile icon (top right in Azure DevOps).
2. Select “Personal Access Tokens”.
3. Click “New Token”.
4. Give permissions:
   - Agent Pools (Read & Manage)
5. Copy the token.

--------------------------------------------------
PART 8: RUN AGENT
--------------------------------------------------
1. Run:
   run.cmd
2. Agent will connect to Azure DevOps.

--------------------------------------------------
PART 9: VERIFY AGENT
--------------------------------------------------
1. Go back to Agent Pools.
2. Open your pool.
3. Confirm agent status shows “Online”.

--------------------------------------------------
DONE
--------------------------------------------------
You now have:
- A working CI pipeline using Maven
- A self-hosted agent connected to Azure DevOps

package com.example.demo;

import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.*;

@Controller
public class HelloController {

```
@GetMapping("/")
public String home() {
    return "home";
}

@PostMapping("/greet")
public String greet(@RequestParam String name, Model model) {
    if (name.equals("admin")) {
        return "redirect:/success";
    } else {
        model.addAttribute("error", "Invalid User");
        return "home";
    }
}

@GetMapping("/success")
public String success() {
    return "success";
}
```

}

```

@Test
public void testSuccess() throws Exception {
    mockMvc.perform(post("/greet")
            .param("name", "admin"))
            .andExpect(status().is3xxRedirection())
            .andExpect(redirectedUrl("/success"));
}

@Test
public void testFailure() throws Exception {
    mockMvc.perform(post("/greet")
            .param("name", "user"))
            .andExpect(status().isOk())
            .andExpect(view().name("home"))
```
